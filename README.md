# py-multi-study-notebook

> 个人学习笔记本 —— 以 Jupyter Notebook 形式整理的多主题学习笔记。

## 笔记列表

| 笔记文件 | 主题 |
|----------|------|
| `Python.ipynb` | Python 基础 |
| `Py_class.ipynb` | Python 面向对象 |
| `Py_iter.ipynb` | 迭代器与生成器 |
| `Py_Thread.ipynb` | Python 多线程 |
| `Py_Reptiles.ipynb` | Python 爬虫 |
| `Py_django.ipynb` | Django Web 框架 |
| `Py_vir.ipynb` | Python 虚拟环境 |
| `Javascript.ipynb` | JavaScript 基础 |
| `Flutter.ipynb` | Flutter 跨平台开发 |
| `Linux.ipynb` | Linux 常用操作 |
| `Ubuntu.ipynb` | Ubuntu 环境配置 |

## 使用方式

```bash
pip install notebook   # 或使用 jupyterlab
jupyter notebook       # 启动后选择对应 ipynb 浏览
```

## 说明

- 笔记以代码片段 + 注释为主，按学习时间顺序累积；
- 部分笔记为早期整理，保留原始记录供回顾。
